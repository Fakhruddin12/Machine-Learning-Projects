# Predicting Vehicle Fuel Economy

**Can vehicle characteristics help predict miles per gallon?**

The notebook starts with exploratory analysis, then uses a random-forest regression model to predict fuel economy. The useful comparison is prediction error against a simple reference, rather than how closely the model fits the training records.

## Inspect the work

[Open the notebook](Car-mpg-Prediction.ipynb) · [Included data](car-data.csv)

Read the imports and data-loading cells before running this historical notebook. Install a compatible environment and run from this folder; this documentation review did not rerun the model.

## Interpretation

This is an early learning exercise. Saved notebook outputs were not rerun or promoted as a current benchmark. A new evaluation should check split construction, missing-value handling and performance across different vehicle groups.
