# Classifying Tumour Measurements

**Can a model distinguish the supplied tumour labels from a table of measurements?**

This early notebook explores the data and fits a support-vector classifier. It demonstrates a supervised classification workflow rather than a clinical diagnostic system.

## Interpretation

Earlier accuracy and zero-false-negative observations belong to a particular historical sample. They were not revalidated here and do not establish safety or performance on new patients. The class definition, split, preprocessing and confusion matrix should be inspected before interpreting any saved score.
