These notebooks reflect earlier experiments and library versions. Their outputs have not been revalidated as part of the portfolio refresh. Old sample accuracy, zero-error observations or candidate-pair screens should not be interpreted as clinical validation, future performance or a profitable backtest. A universal environment file is not asserted for notebooks using different generations of TensorFlow and scikit-learn.
