## How to read the evidence

These are historical learning notebooks, not the strongest evidence for my current research. Their saved outputs were not revalidated during this README review. Earlier sample accuracy, zero-false-negative results or counts of apparently profitable pairs do not establish clinical performance, future returns or robustness to model selection.

The [dedicated volatility repository](https://github.com/Fakhruddin12/hmm-regime-volatility-forecasting) supersedes the original volatility experiment with a genuinely forward-looking target and stronger evaluation controls. [Current portfolio and project index](https://github.com/Fakhruddin12/Fakhruddin12/blob/main/PROJECTS.md).

Each notebook has its own data and library assumptions; one universal modern environment is not asserted for all of them. Historical code and data have been retained rather than represented as newly executed work.
