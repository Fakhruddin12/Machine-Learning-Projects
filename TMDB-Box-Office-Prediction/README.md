# Predicting Movie Box-Office Revenue

**Which recorded movie attributes help predict revenue?**

The notebook cleans movie records, constructs features and compares an initial random forest with tuned configurations using randomised and grid search.

## Inspect the work

[Open the notebook](TMBD_Box_Office_Prediction.ipynb) · [Included data](train.csv)

Read the imports and data-loading cells before running this historical notebook. Install a compatible environment and run from this folder; this documentation review did not rerun the model.

## Interpretation

This is a historical prediction exercise, not an investment forecast. A prospective model must restrict inputs to information actually known at the forecast date. Saved results were not rerun during this documentation review.
