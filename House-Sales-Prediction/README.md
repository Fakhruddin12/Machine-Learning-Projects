# Predicting House Sale Prices

**How much can recorded property features tell us about a house sale price?**

This notebook explores house-sale data and builds a TensorFlow wide-and-deep regression model. Its feature engineering includes bucketed and crossed features, combining simple effects with a nonlinear network.

## Inspect the work

## Interpretation

The notebook uses older TensorFlow APIs and may need a compatible historical environment. Saved scores were not revalidated here. Future-market performance would require an appropriately dated test; a random sample alone would not establish that.
